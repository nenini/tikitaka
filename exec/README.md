## 시스템 구성

```
                    ┌───────────────────────────────┐
  브라우저  ──443──▶ │ nginx 1.27  (호스트, TLS 종료) │
                    └───────────────────────────────┘
                       │  /          │ /api  /ws     │ /ai/face/
                       ▼             ▼               ▼
                  frontend       backend         face-analysis
                  (nginx+정적)   (Spring Boot)    (FastAPI)
                                     │
                        ┌────────────┼────────────┐
                        ▼            ▼            ▼
                     MySQL 8.4    LiveKit      chatbot / aggregator
                                  (외부)        (FastAPI + Ollama)
```

- 브라우저 ↔ 서버 실시간: **STOMP over WebSocket** (`/ws`)
- 브라우저 ↔ 브라우저 미디어: **LiveKit (WebRTC)**
- 표정 분석은 **브라우저에서 계산**하고 지표만 LiveKit DataChannel 로 AI 워커에 보낸다.
  원본 영상 프레임은 브라우저를 떠나지 않는다.
