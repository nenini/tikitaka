## 1.2 환경 변수

`.env.prod.example` 이 **키 목록의 정본**이다. 이걸 복사해 값을 채운다.

```bash
cp .env.prod.example /opt/a307/.env.prod
```

### 필수 — 이 값이 없으면 뜨지 않는다

| 키 | 설명 |
|---|---|
| `MYSQL_DATABASE` · `MYSQL_USER` · `MYSQL_PASSWORD` · `MYSQL_ROOT_PASSWORD` | DB 계정 |
| `JWT_SECRET` | 액세스·리프레시 토큰 서명 키. **32바이트 이상 랜덤** |
| `FRONTEND_BASE_URL` | OAuth 리다이렉트·메일 링크의 기준 주소 |

### 기능별 — 없으면 그 기능만 꺼진다

| 기능 | 키 |
|---|---|
| 구글 로그인 | `GOOGLE_OAUTH_CLIENT_ID` · `GOOGLE_OAUTH_CLIENT_SECRET` · `GOOGLE_OAUTH_REDIRECT_URI` |
| 네이버 로그인 | `NAVER_OAUTH_CLIENT_ID` · `NAVER_OAUTH_CLIENT_SECRET` · `NAVER_OAUTH_REDIRECT_URI` |
| 화상 세션 | `LIVEKIT_URL` · `LIVEKIT_API_KEY` · `LIVEKIT_API_SECRET` |
| 메일(비밀번호 재설정) | `MAIL_HOST` · `MAIL_PORT` · `MAIL_USERNAME` · `MAIL_PASSWORD` · `MAIL_FROM` |
| AI 챗봇 | `AI_CHAT_BASE_URL` · `AI_CHAT_INTERNAL_TOKEN` · `OLLAMA_HOST` |
| AI 세션 분석 | `AI_SESSION_BASE_URL` · `AI_SESSION_INTERNAL_TOKEN` |
| 전사(STT) | `AI_TRANSCRIPT_BASE_URL` · `AI_TRANSCRIPT_INTERNAL_TOKEN` |

### 조정 가능 (예제 파일 기준값)

| 영역 | 키 | 예제값·설명 |
|---|---|---|
| 이미지·포트 | `APP_VERSION` · `BACKEND_PORT` | `latest` · `8080`. 배포 스크립트가 실제 릴리스 태그를 붙인다 |
| JWT | `JWT_ACCESS_TOKEN_VALIDITY_SECONDS` · `JWT_REFRESH_TOKEN_VALIDITY_SECONDS` | `1800`(30분) · `1209600`(14일) |
| 비밀번호 재설정 | `PASSWORD_RESET_TOKEN_VALIDITY_SECONDS` · `PASSWORD_RESET_URL` | `900`(15분) · 운영 재설정 화면 URL |
| OAuth | `OAUTH_STATE_VALIDITY_SECONDS` · `OAUTH_SECURE_COOKIE` | `300` · 운영 `true` |
| 메일 | `MAIL_SMTP_AUTH` · `MAIL_SMTP_STARTTLS` · `MAIL_HEALTH_ENABLED` | `true` · `true` · `false` |
| LiveKit | `LIVEKIT_EMPTY_TIMEOUT_SECONDS` · `LIVEKIT_MAX_PARTICIPANTS` | `600` · `3`(사용자 2 + AI 워커 1) |
| 챗봇 호출 | `AI_CHAT_STREAM_PATH` · `AI_CHAT_CONNECT_TIMEOUT` · `AI_CHAT_REQUEST_TIMEOUT` | `/api/v1/chat/stream` · `3s` · `60s` |
| Ollama | `OLLAMA_MODEL` · `OLLAMA_HOST` | `exaone3.5:7.8b` · 운영 역터널 `http://host.docker.internal:18150` |
| 얼굴상 자산 | `FACE_ANALYSIS_ARTIFACTS_DIR` · `FACE_ANALYSIS_DATA_DIR` | `/opt/a307/ai-data/face-analysis/artifacts` · `/opt/a307/ai-data/face-analysis/data` |
| AI 세션 이벤트 | `AI_SESSION_EVENT_PATH` · `AI_SESSION_CONNECT_TIMEOUT` · `AI_SESSION_REQUEST_TIMEOUT` | `/api/v1/sessions/events` · `3s` · `5s` |
| AI 세션 재시도 | `AI_SESSION_EVENT_MAX_ATTEMPTS` · `AI_SESSION_EVENT_RETRY_DELAY` | `3` · `1s` |
| 전사 조회 | `AI_TRANSCRIPT_PATH_TEMPLATE` · `AI_TRANSCRIPT_CONNECT_TIMEOUT` · `AI_TRANSCRIPT_REQUEST_TIMEOUT` | `/api/v1/sessions/{sessionId}/transcript` · `3s` · `15s` |
| 전사 재시도 | `AI_TRANSCRIPT_MAX_ATTEMPTS` · `AI_TRANSCRIPT_RETRY_DELAY` | `5` · `2s` |
| API 문서 | `SPRINGDOC_API_DOCS_ENABLED` · `SPRINGDOC_SWAGGER_UI_ENABLED` | 운영 기본 `false` · `false` |

`AI_TRANSCRIPT_BASE_URL`은 일반적으로 `AI_SESSION_BASE_URL`과 같은 aggregator 주소를
사용한다. 빈 값이면 신고 증거용 전사 조회가 동작하지 않는다.

### 프런트 빌드 시점 변수

Vite 는 **빌드 시점에 값을 굽는다.** 런타임 주입이 안 되므로 이미지 빌드 전에 정해야 한다.

| 키 | 파일 | 비고 |
|---|---|---|
| `VITE_API_BASE_URL` | `frontend/.env.*` | 비우면 `/api` 를 쓴다 |
| `VITE_PROXY_TARGET` | `frontend/.env.local` | **로컬 개발 전용** |

> ⚠️ 폴백에 `??` 가 아니라 `||` 를 쓴다. `VITE_API_BASE_URL=`(빈 문자열)이 `??` 를
> 통과해 경로 프리픽스가 사라지는 버그가 있었다.

## 1.3 로컬에서 빌드·실행

### 사전 준비

MySQL 8.x 를 띄우고 DB·계정을 만든다.

```sql
CREATE DATABASE date CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER 'date'@'%' IDENTIFIED BY '<비밀번호>';
GRANT ALL PRIVILEGES ON date.* TO 'date'@'%';
```

### 백엔드

`bootRun` 은 `.env` 파일을 자동으로 읽지 않는다. DB 접속값을 운영체제 환경 변수로
설정한 다음 실행한다.

```bash
cd backend
export SPRING_PROFILES_ACTIVE=local
export DB_URL='jdbc:mysql://localhost:3306/date?serverTimezone=Asia/Seoul&characterEncoding=UTF-8'
export DB_USERNAME=date
export DB_PASSWORD='<비밀번호>'
./gradlew bootRun
```

Windows PowerShell에서는 `export` 대신 아래처럼 설정한다.

```powershell
cd backend
$env:SPRING_PROFILES_ACTIVE = 'local'
$env:DB_URL = 'jdbc:mysql://localhost:3306/date?serverTimezone=Asia/Seoul&characterEncoding=UTF-8'
$env:DB_USERNAME = 'date'
$env:DB_PASSWORD = '<비밀번호>'
.\gradlew.bat bootRun
```

Flyway 가 기동 시 `V1`~`V63` 마이그레이션(총 47개 파일)을 자동 적용한다. **별도 DDL 실행이 필요 없다.**

### 프런트

**순서가 중요하다.** vision 패키지를 먼저 빌드해야 한다.

```bash
cd ai/vision-analysis && npm install && npm run build
cd ../../frontend && npm install
npm run dev
```

`frontend` 의 `postinstall` 이 MediaPipe 모델(`face_landmarker.task`,
`hand_landmarker.task`)을 `public/models/` 로 내려받는다. **둘 다 있어야** 표정 분석이 돈다.

### AI 서비스

챗봇과 얼굴상 분석 API는 다음처럼 실행한다.

```bash
cd ai
docker compose up -d chatbot face-analysis
```

- 챗봇은 호스트의 Ollama(`11434`)에 연결한다. 모델은 미리 내려받아야 한다.
- face-analysis는 Git에 없는 모델·참조 데이터를 먼저 준비해야 한다.
  - `ai/face-analysis/artifacts/face_detection_yunet_2023mar.onnx`
  - `ai/face-analysis/artifacts/.deepface/weights/facenet512_weights.h5`
  - `ai/face-analysis/data/processing_report.csv`
  - `ai/face-analysis/data/processed/` 아래 참조 이미지

실시간 STT·코칭·리포트를 처리하는 `aggregator`는 NVIDIA GPU와 백엔드 공유 토큰이
필요한 별도 관제 서비스다. `ai/docker-compose.yml`의 `device_ids`를 실행 서버 GPU 번호에
맞추고 다음처럼 실행한다.

```bash
cd ai
AI_SESSION_INTERNAL_TOKEN='<백엔드와 같은 값>' \
BACKEND_BASE_URL='http://host.docker.internal:8080' \
docker compose up -d aggregator
```

운영용 루트 `docker-compose.prod.yml`에는 aggregator가 없다. 운영 관제 서버에서 따로
실행하고, 백엔드의 `AI_SESSION_BASE_URL`·`AI_TRANSCRIPT_BASE_URL`을 그 주소로 설정한다.

| 서비스 | 호스트 포트 |
|---|---|
| chatbot | 8000 |
| face-analysis | 8001 |
| aggregator | 8002 |

Ollama 는 컨테이너 밖(호스트 `11434`)에서 따로 띄운다.

| 백엔드 | 8080 |

## 1.4 운영 배포

### 구조

Jenkins 파이프라인이 빌드·테스트·이미지 생성까지 하고, `scripts/deploy-prod.sh` 가 교체한다.

```
Checkout → Backend Test → Vision Package Build → Frontend Check
  → Backend/Frontend/AI 이미지 빌드 → Deployment Decision → Deploy Production
```

### 서버 배치

| 경로 | 내용 |
|---|---|
| `/opt/a307/app` | `docker-compose.prod.yml` · `nginx/` |
| `/opt/a307/.env.prod` | **비밀값** (git 미추적) |
| `/etc/letsencrypt/live/i15a307.p.ssafy.io/` | TLS 인증서 |

### 수동 배포

```bash
cd /opt/a307/app && DEPLOY_DIR=/opt/a307/app ENV_FILE=/opt/a307/.env.prod ./scripts/deploy-prod.sh
```

### nginx 라우팅

| 경로 | 목적지 |
|---|---|
| `/` | frontend |
| `/api/` · `/ws` · `/actuator/health` | backend |
| `/ai/face/` | face-analysis |
| `/internal/` | backend 내부 API (각 컨트롤러가 `X-Internal-Token` 검증) |
| `/.well-known/acme-challenge/` | 인증서 갱신 |

## 1.5 배포 시 특이사항

**① 컨테이너에서 외부로 나가는 포트는 80·443 둘뿐이다.**
백엔드는 `127.0.0.1:8080` 에만 바인딩된다 — 외부에서 직접 붙을 수 없다.

**② `deploy-prod.sh` 는 롤백을 준비하고 시작한다.**
기존 이미지를 `rollback-<빌드번호>` 로 태그해 두고, 헬스체크가 실패하면 되돌린다.
`/tmp/a307-prod-deploy.lock` 으로 동시 배포를 막는다.

**③ Flyway 는 되돌리지 않는다.**
마이그레이션은 앞으로만 간다. 스키마 변경을 되돌리려면 새 마이그레이션을 추가한다.

**④ MediaPipe 모델(.task)은 정적 자산이라 SPA 폴백에서 제외해야 한다.**
`frontend/nginx/default.conf` 의 `location ^~ /models/` 가 그 역할을 한다.
빠지면 nginx 가 `index.html` 을 200 으로 돌려주고 브라우저는 `SyntaxError` 를 낸다.

**⑤ 프런트 환경 변수는 이미지 빌드 시점에 굳는다.** 바꾸려면 재빌드해야 한다.

**⑥ Ollama 는 이 compose 가 띄우지 않는다.** 챗봇 컨테이너는 EC2 에서 돌고
**GPU 가 달린 별도 머신의 Ollama 로 역터널**(`host.docker.internal:18150`)을 통해 호출한다.

- 역터널이 살아 있어야 챗봇·리포트 문장 생성이 된다. 끊겨도 **화상 세션·매칭은 영향 없다.**
- GPU 서버에 모델이 미리 받아져 있어야 첫 요청이 다운로드를 기다리다 타임아웃되지 않는다.

```bash
ollama pull exaone3.5:7.8b
```

**⑦ AI 화상 트랙은 서버 세션이 없다.** `/ai-video/*` 는 브라우저 안에서만 도는
혼자 연습 모드다. 별도 배포 대상이 아니다.

## 1.6 계정·프로퍼티가 정의된 파일 목록

### 값이 들어 있는 파일 (전부 git 미추적)

| 파일 | 담긴 것 |
|---|---|
| `/opt/a307/.env.prod` | 운영 DB 계정 · JWT · OAuth · LiveKit · SMTP · AI 내부 토큰 |
| `backend/.env` | 로컬 개발용 동일 항목 |
| `frontend/.env.local` | `VITE_PROXY_TARGET` 등 로컬 설정 |

### 키 이름만 정의된 파일 (git 추적)

| 파일 | 역할 |
|---|---|
| `.env.prod.example` | **운영 환경 변수 키 목록의 정본** |
| `backend/.env.example` | 로컬 키 목록 |
| `backend/src/main/resources/application.yml` | 공통 설정 + `${ENV:기본값}` 매핑 |
| `application-local.yml` · `application-prod.yml` · `application-test.yml` | 프로필별 오버라이드 |
| `docker-compose.prod.yml` | 컨테이너에 넘길 환경 변수 매핑 |
| `frontend/.env.example` | 프런트 키 목록 |

### ERD 관련 DB 접속 정보

DB 접속 정보는 **`.env.prod` 의 `MYSQL_*` 4개**가 전부다. 애플리케이션은
`application-prod.yml` 에서 이 값을 읽는다. 소스에 하드코딩된 접속 정보는 없다.

> ⚠️ git 히스토리(`809eacd`, 과거 `backend/.env.example`)에 **구버전 OAuth 키가
> 노출돼 있다.** 해당 키는 발급처(Google Cloud Console)에서 폐기했다.
> 히스토리 재작성은 하지 않았다.
