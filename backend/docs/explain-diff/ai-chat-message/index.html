BACKEND · AI_CHAT-02

AI 채팅 메시지 저장 및 조회

사용자·AI 메시지를 세션 안에서 순서대로 저장하고, 오직 세션 소유자만 전체 대화 기록을 조회하도록 변경했습니다.

✓ 전체 테스트 96개 통과

변경 전후

BEFORE · 세션만 관리

chatbot_messages 테이블은 있었지만 JPA 엔티티·저장 API·조회 API가 없었습니다. 메시지 순서를 보장하는 값도 없었습니다.

AFTER · 대화 기록 관리

senderType, messageText, sequenceNo, createdAt을 응답하며 세션별 순서를 DB 유일 제약으로 보호합니다.

API

{
  "senderType": "USER",
  "messageText": "안녕하세요.",
  "proactive": false
}

{
  "messageId": 31,

  "messageText": "반갑습니다.",
  "sequenceNo": 2,

  "createdAt": "2026-07-27T09:30:00"
}

변경목적
sequenceNo BIGINT NOT NULL세션 내부 메시지 발생 순서 기록
기존 행 순번 백필생성 시각과 PK를 기준으로 1부터 번호 부여
UNIQUE(conversationId, sequenceNo)같은 세션의 중복 순번 DB 차단
세션·생성 시각 인덱스세션별 메시지 조회 성능 보조

권한과 오류

상황응답
JWT 없음401 Unauthorized
다른 사용자의 세션403 CHAT_SESSION_FORBIDDEN
없는 세션404 CHAT_SESSION_NOT_FOUND
정상 저장201 Created
정상 조회200 OK · sequenceNo 오름차순

현재 AI 서버 연동 전 단계이므로 저장 요청은 USER와 AI 유형을 모두 받을 수 있습니다. 이후 Backend↔AI 내부 인증을 붙일 때 AI 메시지 저장 경로를 내부 전용으로 제한하는 것이 권장됩니다.
