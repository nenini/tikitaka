## F1. 온보딩 — 가입부터 매칭 가능 상태까지

```mermaid
flowchart TD
    S([방문]) --> L["랜딩·로그인 [01]<br/>AUTH-01"]
    L -->|기존 회원| HOME([홈으로])
    L -->|신규| R["회원가입 [02]<br/>이메일/소셜 · AUTH-01"]
    R --> AGE{"성인 확인<br/>AUTH-02"}
    AGE -->|미성년| BLOCK[/"⚠ 가입 차단 안내<br/>서비스 이용 불가"/]
    AGE -->|성인| CONSENT["목적별 동의 [03]<br/>AUTH-03"]

    CONSENT --> CGATE{"필수 약관<br/>동의?"}
    CGATE -->|거부| BLOCK2[/"⚠ 가입 진행 불가<br/>(필수 항목)"/]
    CGATE -->|동의| OPT{"선택 동의<br/>(얼굴·표정·음성·리포트)"}

    OPT -->|"◆ 얼굴 분석 거부"| PROF
    OPT -->|"◆ 전부 동의"| PROF["기본 프로필 [04]<br/>PROFILE-01"]

    PROF --> FACE{"얼굴 분석<br/>동의했나?"}
    FACE -->|아니오| SURVEY
    FACE -->|예| CAM["실시간 얼굴 촬영 [05]<br/>PROFILE-02"]
    CAM --> CAMOK{촬영 검증}
    CAMOK -->|"⚠ 미감지/다중/가림"| CAM
    CAMOK -->|"⚠ 조명 부족"| CAM
    CAMOK -->|통과| TAG["얼굴상 태그 결과 [05b]<br/>PROFILE-03 · 공개 여부 선택"]
    TAG --> SURVEY["설문 [06]<br/>이상형 SURVEY-01 · 성향 SURVEY-02<br/>연습 목표 PROFILE-05"]

    SURVEY --> TIME["가능 시간대 입력 [07]<br/>MATCH-02-1 · 주 단위"]
    TIME --> LV0["연습 레벨 0 부여<br/>SURVEY-03 · 진단 설문 없음"]
    LV0 --> HOME
```

**핵심 규칙**
- 선택 동의를 **모두 거부해도** 기본 화상 연습(홈 진입·매칭·세션)은 가능하다. 거부 시 해당 AI 분석 기능만 비활성(세션 중 코칭 미제공, 리포트는 지표 기반 축소판).
- 얼굴 분석 거부 시 얼굴상 태그 없음 → 매칭의 "선호 분위기 적합도"는 키·자기소개만으로 계산.

## F2. 매칭 — 트랙 선택부터 세션 확정까지

```mermaid
flowchart TD
    HOME(["홈 [08]"]) --> TRACK{"매칭 트랙 선택<br/>MATCH-01"}
    TRACK -->|AI 가상 상대| BOT([F5 챗봇으로])
    TRACK -->|실사용자| Q["대기 큐 등록<br/>※ 동시 진행 매칭 1개 제한"]

    Q --> FILTER["필수 조건 필터 MATCH-02<br/>상호 대상·연령·시간대 교집합<br/>차단/정지/최근 매칭 제외"]
    FILTER --> SCORE["매칭 점수 산출 MATCH-03<br/>목표30·성향25·관심사20·일정15·분위기10"]
    SCORE --> FOUND{후보 발견?}
    FOUND -->|"⚠ 지연"| WAIT[/"지연 원인 안내<br/>'시간대를 넓히면 빨라져요'"/]
    WAIT --> FILTER
    FOUND -->|성립| CARD["매칭 카드 [09]<br/>닉네임·연령대·키·얼굴상<br/>+ 매칭 근거 문장(D-21)"]

    CARD --> ACCEPT{"양측 수락?<br/>MATCH-06 · 제한 시간 내"}
    ACCEPT -->|"⚠ 한쪽 거절/시간 초과"| Q
    ACCEPT -->|양측 수락| FIX["세션 확정<br/>NOTIFY-01: 확정 + 취소 정책 안내"]

    FIX --> REMIND["리마인드 알림<br/>2시간 전 · 1시간 전 · 10분 전"]
    REMIND --> T{세션 시각}

    FIX -.->|"◆ 내가 취소 (1시간 이전)"| C1[/"레벨 경험치 소폭 감소<br/>노쇼 패널티 없음"/]
    FIX -.->|"◆ 내가 취소 (1시간 이내)"| C2[/"경험치 대폭 감소<br/>노쇼 패널티 1회"/]
    C1 --> Q
    C2 --> Q
    FIX -.->|"◆ 상대 취소"| ALT{"대체 제공"}
    ALT -->|대체 매칭| Q
    ALT -->|챗봇 전환| BOT

    T --> ROOM([F3 대기방 입장])
    T -.->|"⚠ 5분 미입장 = 노쇼"| NOSHOW[/"노쇼 처리 MODERATION-04<br/>패널티 (6개월 단위 소멸)"/]
```

## F4. 세션 후 — 평가 · 리포트 · 연락처 교환

```mermaid
flowchart TD
    S([세션 종료]) --> EVAL["상호 평가 입력 [14]<br/>RESULT-02 · 6항목 1~5점 + 서술(선택)"]
    S -.->|"◆ 신고/차단 확인"| BLK["차단 MODERATION-02<br/>→ 이후 매칭 제외"]

    EVAL --> SUBMIT{내 평가 제출?}
    SUBMIT -->|"⚠ 미제출"| LOCK[/"상대 평가 영역 잠금<br/>(상호성 게이트)"/]
    SUBMIT -->|제출| EXT{"5분 연장 의사?<br/>CONTACT-01"}

    EXT -->|"양측 승인"| FIVE["5분 화상 연장 [15]"]
    FIVE --> SHARE{"연락처 공개 동의?<br/>CONTACT-02"}
    EXT -->|"한쪽이라도 거절"| REPORT
    SHARE -->|양측 동의| OPEN["인스타/카톡 ID 상호 공개<br/>1회성 전달(D-17) + 알림"]
    SHARE -->|"한쪽 거절<br/>(거절 여부 비노출)"| REPORT
    OPEN --> REPORT

    REPORT["AI 리포트 생성 → 알림 [16]<br/>REPORT-01 레이더 · 01-1 이슈 맥락<br/>02 행동 근거 · 04 요약"]
    REPORT --> PEER{상대 평가 도착?}
    PEER -->|도착| FULL["리포트 완성판<br/>AI vs 상대 비교"]
    PEER -->|"⚠ 48시간 미제출(D-12)"| AIONLY["AI 분석만으로 확정<br/>미제출자는 매칭 후순위"]

    FULL --> LEVEL["연습 레벨 갱신 SURVEY-03<br/>상호 평가 + AI 피드백 + 매너 감점"]
    AIONLY --> LEVEL
    LEVEL --> DASH["성장 대시보드 반영 [17]<br/>GROWTH-01 히스토리"]
    DASH --> HOME([홈으로 · 다음 세션])
```

## F5. AI 챗봇 트랙 (텍스트 전용 · 화상 없음)

```mermaid
flowchart TD
    S([트랙 선택: AI]) --> PHASE{"연습 단계 선택"}
    PHASE -->|"소개팅 전<br/>(사전 대화)"| SETUP
    PHASE -->|"소개팅 후<br/>(애프터 대화)"| SETUP["페르소나 설정 [10]<br/>AI-DATE-02 · 말투 중심<br/>+난이도·성향·반응·주제"]
    SETUP --> CHAT["챗봇 대화 AI-DATE-01<br/>즉각 반응형 · 24시간"]
    CHAT --> IDLE{"12시간 무응답?"}
    IDLE -->|아니오| CHAT
    IDLE -->|"예 (1회 한정)"| PING{"현재 야간<br/>00–09시?"}
    PING -->|"예 (D-05)"| HOLD[/"발송 보류<br/>아침까지 대기"/] --> FIRST
    PING -->|아니오| FIRST["시간대별 선톡 1회 + 알림<br/>재발송 없음"]
    FIRST --> CHAT
    CHAT -->|대화 종료| HOME([홈으로])
```
