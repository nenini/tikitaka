BloomTalk · 와이어플로우 (틀 · 시나리오 단계)

시나리오별 화면 구성 — 데스크탑 + 앱뷰 나란히

화상 모의 소개팅 + AI 코칭 서비스. 데스크탑 웹 우선 · 앱뷰 지원이라 각 화면을 데스크탑과 모바일(앱뷰) 두 버전으로 나란히 배치했다. 각 노드는 아직 실제 화면이 아니라 배치·정보구조만 담은 스켈레톤 목업(mockups/)을 iframe으로 축소 삽입한 것. 이번 단계는 화살표·분기 없이 시나리오(S1~S9)로 화면만 나눈다 — 유저플로우 연결과 실제 화면 대체는 와이어프레임 확정 후 진행.

데스크탑 = mockups/desktop/SC-xx.html 모바일(앱뷰) = mockups/phone/SC-xx.html ⭐ 핵심·크리티컬 시나리오 관리자 = 데스크탑 웹 전용(앱뷰 없음)
S1

온보딩 — 가입·동의·프로필·얼굴상·설문

신규 사용자 P0

3초 소셜 로그인 → 연령 확인 → 목적별 개인정보 동의 → 기본 프로필 → 실시간 얼굴 촬영으로 얼굴상 태그 → 이상형·성향 설문 → 주 단위 가능 시간대. 성공 기준: 프로필 + 기본 온도 36.5°.

S2

매칭 — 트랙 선택·조건 필터·수락

사용자 P0

AI 챗봇 / 실사용자 화상 트랙 선택 → 필수 조건 필터(시간·나이·차단) + 다차원 점수 → 매칭 대기 큐 → 성립 시 양측 수락. 화상 30분은 실사용자 트랙 전용.

S3

실사용자 화상 세션 — 대기방·30분·실시간 코칭

사용자 P0 ⭐

상황형 대기방(장소 자동 배정·기기 점검·동의 게이트) → 30분 WebRTC 화상 → 본인 화면에만 실시간 코칭(표정·발화·침묵 단계 개입·질문 카드). ⚠️ 크리티컬 패스.

S4

세션 종료 — 상호 평가·AI 리포트

사용자 P0

원본 영상 미저장·지표만 집계 → 행동 기반 상호 평가(상호성 게이트: 상대 평가 제출 후 내 평가 열람) → 레이더 리포트(AI 분석 vs 상대 평가·근거 인용) → 사랑의 온도 갱신.

S5

연락처 교환 — 애프터 5분·상호 동의

사용자 P0

만족스러운 세션 후 양측 동의 시에만 5분 화상 연장 → 인스타·카톡 아이디 상호 공개(내부 쪽지 채널). 한쪽만 동의 시 거절 여부 비표시.

S6

AI 가상 상대 — 챗봇 연습

사용자 P0

대기 없이 즉시 연습하는 텍스트 챗봇(소개팅 전/후 단계·말투 페르소나). 12시간 무응답 시 시간대별 멘트로 1회 선톡. 화상 트랙은 P2 보류.

S7

홈 · 성장 — 대시보드·뱃지·마이

사용자 P0 · P1

홈(오늘의 연습·예약) → 성장 대시보드(누적 그래프·강점/보완 키워드·성장 뱃지) → 마이페이지(사랑의 온도 이력·동의 철회).

S8

안전 · 알림 — 신고·차단·노쇼

사용자 P0 · P1

세션 중 실시간 신고·즉시 종료 → 차단(매칭 후보 제외). 노쇼·직전 취소는 사랑의 온도 차감 + 노쇼 패널티(6개월 갱신). 알림 센터(매칭·리마인드·리포트·선톡).

S9

관리자 — 회원·신고·정책

운영자 (웹 전용) P1

회원/신고 관리·제재(AI 감지만으로 영구정지 금지) · 매칭/코칭 정책 가중치 · 상황형 배경 · 얼굴상 연예인·질문 풀 관리. 관리자 화면은 데스크탑 웹 전용.
