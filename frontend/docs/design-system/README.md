# Tika Web Design System

> `Fixa | Mobbin`의 Fixa 프리뷰에서 추출한 시네마틱 히어로, 절제된 정보 위계, 캡슐형 UI를 Tika의 로고·청춘 촬영 이미지에 맞게 재해석한 웹 디자인 규약이다.

## 1. 기준과 적용 범위

### 관찰된 원본 구조

- Mobbin 상세 페이지 껍데기: 사이트 정보, Preview/Sections 탭, 16:10 프리뷰, 추천 사이트 영상 그리드.
- Fixa 본편 첫 화면: 화면을 채우는 저각도 인물 영상, 역광과 렌즈 플레어, 중앙의 대형 흰색 카피, 상단 중앙의 작은 흰색 내비게이션, 하단의 짧은 설명과 단일 CTA.
- Fixa 프리뷰는 `autoplay`, `loop`, `playsinline`, `object-fit: cover` 형태의 무음 영상이며 16:10 레터박스 컨테이너 안에서 재생된다.
- 원본은 720/840/1280px을 주요 전환 폭으로 사용하고, 큰 화면에서 외곽 패딩과 둥근 프레임을 추가한다.

### 가져올 것 / 가져오지 않을 것

가져올 것은 **시네마틱 인물 중심 비주얼, 한 화면 한 메시지, 작은 캡슐 UI, 자연광 촬영, 짧은 루프 영상**이다. Mobbin의 검색창, Pro 배너, 메타데이터, 추천 카드 그리드는 새 브랜드 경험과 무관하므로 복제하지 않는다.

### 핵심 원칙

1. **Human first** — 기능보다 사람의 표정·움직임·관계를 먼저 보여준다.
2. **One scene, one sentence** — 한 화면에서 주장 하나와 주요 행동 하나만 강조한다.
3. **Calm over clutter** — 장식보다 여백, 대비, 속도 조절로 감정을 만든다.
4. **Editorial, not corporate** — 정형화된 제품 스크린샷보다 영화의 한 장면 같은 프레이밍을 우선한다.
5. **Accessible by default** — 영상이 없어도 메시지와 행동이 완전해야 한다.

## 2. 브랜드 방향

- 성격: 다정함, 청춘, 솔직함, 기록, 약간의 장난기.
- 시각적 대비: 검정/아이보리의 또렷한 UI + 숲의 녹색 + 햇빛의 따뜻한 금색 + 작은 분홍 포인트.
- 로고 역할: 필기체 Tika 로고는 감성 장치, 본문 산세리프는 정보 장치로 분리한다.
- 로고를 큰 문장처럼 남용하지 않는다. 내비게이션에서는 높이 24~30px, 히어로 오버레이에서는 최대 너비 180px을 권장한다.

## 3. Foundations

실제 구현 값은 [`tokens.css`](./tokens.css)를 단일 기준으로 사용한다.

### Color

| 토큰 | 값 | 용도 |
|---|---:|---|
| Ink | `#0B0D0C` | 본문, 다크 배경, 강한 CTA |
| Paper | `#F8F6F0` | 기본 밝은 배경 |
| White | `#FFFFFF` | 영상 위 텍스트, 역상 UI |
| Forest | `#083E2B` | Tika 핵심 브랜드색 |
| Moss | `#496653` | 보조 텍스트, 아이콘, 태그 |
| Leaf | `#A7BE9C` | 약한 면, 상태 배경 |
| Sun | `#F0C96B` | 햇빛 계열 강조, 하이라이트 |
| Blush | `#EAB4C2` | 하트/대화 포인트, 제한적 사용 |
| Line | `rgba(11,13,12,.14)` | 밝은 배경 경계선 |
| Scrim | `rgba(5,12,9,.36)` | 영상 위 가독성 보정 |

규칙:

- 한 섹션에는 브랜드색 1개와 포인트색 1개까지만 쓴다.
- Blush와 Sun은 전체 화면 면적의 합계 10% 이하로 제한한다.
- 영상 위 흰색 텍스트에는 국소 영역 기준 최소 4.5:1 대비가 확보되도록 그라디언트 스크림을 둔다.

### Typography

| 스타일 | 데스크톱 | 모바일 | 권장 |
|---|---:|---:|---|
| Display | 72/0.94 | 48/0.98 | 히어로 한 문장, 최대 3줄 |
| H1 | 56/1.02 | 40/1.05 | 페이지 제목 |
| H2 | 40/1.10 | 32/1.12 | 섹션 제목 |
| H3 | 28/1.18 | 24/1.20 | 카드 제목 |
| Body L | 20/1.55 | 18/1.55 | 리드 문장 |
| Body | 16/1.60 | 16/1.60 | 본문 |
| Label | 13/1.20 | 13/1.20 | 캡슐, 메타 정보 |

- 기본: `Pretendard Variable`, `SUIT Variable`, `Noto Sans KR`, sans-serif.
- 영문 감성 강조: `Cormorant Garamond Italic`, Georgia, serif. Fixa처럼 문장 전체가 아닌 핵심 단어 1~3개에만 쓴다.
- 한국어 문장에 억지로 영문 이탤릭을 섞지 않는다. 한글 감성 강조는 굵기 400, 자간 `-0.03em`, 크기 대비로 해결한다.
- 본문 한 줄은 45~70자, 히어로 제목은 8~14단어를 권장한다.

### Spacing, radius, depth

- 간격은 4px 기반: 4, 8, 12, 16, 24, 32, 48, 64, 96, 120.
- 화면 좌우 여백: 모바일 20px, 태블릿 32px, 데스크톱 48~64px.
- 콘텐츠 최대 폭: 1280px. 긴 본문 최대 폭: 720px.
- 카드 반경: 16~24px. 작은 컨트롤: 10~12px. Pill은 `999px`.
- 그림자는 정보 구분용이 아니라 떠 있는 내비게이션·CTA에만 사용한다.

### Breakpoints

- `720px`: 모바일/태블릿 전환, 영상 프레임 반경과 패딩 적용.
- `840px`: 내비게이션과 2열 레이아웃 전환.
- `1280px`: 최대 콘텐츠 폭과 3열 카드 전환.

## 4. Layout system

### 권장 페이지 흐름

1. **Cinematic Hero** — 100svh, 영상/포스터, 중앙 카피, 상단 내비게이션, 하단 CTA.
2. **Promise Strip** — 제품 가치 3개 이하. 아이콘보다 짧은 문장 우선.
3. **Editorial Story** — 큰 사진 1장 + 짧은 텍스트. 좌우를 번갈아 배치.
4. **How it feels** — 기능 목록이 아니라 사용 장면 3개를 카드로 보여준다.
5. **Quote / Social proof** — 한 화면 한 인용문.
6. **Final CTA** — 첫 화면과 같은 문구·같은 행동으로 닫는다.
7. **Quiet Footer** — 법적 링크, SNS, 연락처만 둔다.

### Grid

- 데스크톱: 12열, gutter 24px.
- 태블릿: 8열, gutter 20px.
- 모바일: 4열, gutter 16px.
- 히어로 카피는 데스크톱 4~8열, 모바일 전체 폭 안에서 중앙 정렬한다.
- 텍스트와 피사체가 겹칠 때는 피사체 얼굴보다 카피를 옮긴다. 얼굴 위 그라디언트로 문제를 감추지 않는다.

## 5. Component contracts

### `CapsuleNav`

- 히어로 상단 중앙에 배치하며 top safe area는 20~24px.
- 밝은 영상: Paper 배경 + Ink 텍스트. 어두운 영상: 반투명 Ink 배경 + White 텍스트.
- 높이 40~44px, 좌우 패딩 14~18px, 로고와 메뉴 사이 16px.
- 모바일은 로고 + 메뉴 버튼만 표시하고 펼친 메뉴는 별도 full-screen sheet로 연다.
- 모든 클릭 영역은 최소 44×44px, 키보드 포커스 링은 3px 이상.

### `CinematicHero`

- `min-height: 100svh`; 데스크톱 권장 비율 16:10, 모바일은 별도 4:5 또는 9:16 소스.
- 배경은 `<video>` + `poster`; `object-fit: cover`; 콘텐츠는 독립된 DOM 레이어.
- 영상 위에는 전체 스크림 10~20%와 하단 그라디언트 35~50%를 별도로 둔다.
- 중앙 카피 폭은 `min(760px, 88vw)`, 하단 CTA 영역은 bottom safe area 24px 이상.
- 기본 정렬은 중앙이지만 인물의 시선과 네거티브 스페이스에 따라 4~8열 안에서 이동할 수 있다.

### `HeroHeadline`

- 산세리프 본문 + 영문 이탤릭 강조 단어의 2계층 구조.
- 줄바꿈은 의도적으로 지정하되 모바일/데스크톱 두 경우만 관리한다.
- 텍스트 그림자는 사용하지 않는다. 필요하면 배경 스크림을 조정한다.

### `FloatingCTA`

- 하단에 짧은 보조 문장과 Primary 버튼을 한 묶음으로 둔다.
- 데스크톱은 한 줄, 모바일은 2행. 버튼 높이 44~48px.
- 한 화면에 Primary CTA는 하나만 둔다. Secondary는 텍스트 링크로 처리한다.

### `EditorialMedia`

- 비율: 16:9, 4:5, 1:1 중 하나만 선택한다. 임의 높이 사용 금지.
- 데스크톱에서 텍스트 4열 + 미디어 8열, 다음 섹션은 반대로 교차한다.
- 캡션은 이미지 아래 12px 간격, Label 스타일과 Moss 색을 사용한다.

### `StoryCard`

- 모바일 1열, 태블릿 2열, 데스크톱 최대 3열.
- 이미지 4:5 또는 1:1, 제목 최대 2줄, 설명 최대 3줄.
- 카드를 과도하게 띄우지 말고 배경색 또는 1px Line으로 구분한다.

### `QuoteBlock`

- 최대 폭 920px, H2 크기, 2~4줄.
- 인용 부호 이미지는 쓰지 않고 텍스트와 여백으로 표현한다.

### `Button`

- Primary: Ink 배경/White 텍스트. Hero inverse: White 배경/Ink 텍스트.
- Secondary: 투명 배경/1px 현재색 경계.
- 반경 10~12px 또는 Pill 중 한 체계만 한 화면에서 사용한다.
- Hover는 색 6~8% 변화, Active는 `scale(.98)`, Disabled는 opacity .45.

## 6. Image system

### 촬영 모티브

- 저각도 24~35mm 광각으로 인물을 크게 보이게 하고 하늘·나뭇잎을 네거티브 스페이스로 남긴다.
- 골든아워 또는 나뭇잎 사이 자연광을 역광으로 사용한다.
- 손, 카메라, 옷자락처럼 렌즈 가까이 들어오는 전경 요소를 포함해 몰입감을 만든다.
- 포즈보다 행동을 찍는다: 촬영, 걷기, 서로를 바라보기, 손을 내밀기.
- 색보정은 따뜻한 하이라이트 + 짙은 녹색 그림자. 피부톤은 중립을 유지한다.

### 웹 이미지 규격

| 용도 | 마스터 | 권장 출력 |
|---|---|---|
| Hero desktop | 16:10, 2400×1500 이상 | AVIF/WebP 2400·1600·1200w |
| Hero mobile | 4:5 또는 9:16, 1440px 이상 | AVIF/WebP 1440·960·720w |
| Editorial wide | 16:9, 2000×1125 이상 | AVIF/WebP 2000·1280·768w |
| Story portrait | 4:5, 1600×2000 이상 | AVIF/WebP 1200·800·480w |
| Logo/shape | SVG 우선 | PNG는 2× fallback |

- `srcset`과 `sizes`를 반드시 제공하고, 첫 화면 poster만 eager/high priority로 불러온다.
- 사진 alt는 보이는 행동을 설명한다. 예: “햇빛이 비치는 숲에서 서로를 촬영하는 두 사람”.
- 텍스트가 박힌 래스터 이미지는 금지한다.

## 7. Video direction and delivery

### 12~18초 히어로 루프 촬영안

1. 0~3초: 24mm 저각도, 인물이 렌즈 쪽으로 손을 내민다.
2. 3~6초: 35mm 역광 와이드, 두 사람이 걷거나 서로를 촬영한다.
3. 6~9초: 50mm 손·카메라·표정 디테일.
4. 9~12초: 짧은 핸드헬드 트래킹 또는 원형 이동.
5. 12~15초: 같은 손동작/카메라 이동으로 첫 프레임에 자연스럽게 연결한다.

### 촬영 규격

- 4K 10-bit 원본, 기본 24fps. 슬로모션 컷만 60fps.
- 셔터: 24fps는 1/48~1/50, 60fps는 1/120.
- WB와 노출을 자동으로 두지 않는다. 역광 하이라이트 클리핑을 방지하고 피부를 기준으로 노출한다.
- Hero는 무음 재생을 전제로 하며, 메시지 전달을 대사나 소리에 의존하지 않는다.
- 카메라 흔들림은 감정 표현 수준으로만 허용하고 UI 텍스트가 읽히는 동안은 움직임을 줄인다.

### 웹 인코딩

- MP4/H.264와 WebM/VP9 두 소스, 1080p 데스크톱 + 720p 모바일.
- 12~18초 기준 각 파일 4MB 이하를 목표로 한다. 초과 시 해상도보다 비트레이트와 장면 복잡도를 먼저 조정한다.
- `autoplay muted loop playsinline preload="metadata"`; poster는 영상의 첫 인상과 동일한 프레임.
- `prefers-reduced-motion: reduce`에서는 poster만 보여주고, 재생 버튼을 명시적으로 제공한다.
- 로딩 실패 시 poster → 브랜드 배경색 순서로 폴백한다.

## 8. Motion

- Fast 180ms: hover, press, 작은 메뉴.
- Base 320ms: 카드/시트 진입.
- Slow 600ms: 섹션 reveal, 이미지 교체.
- easing: `cubic-bezier(.22, 1, .36, 1)`.
- reveal 이동 거리는 12~24px, opacity와 함께 사용한다.
- 모바일에서 스크롤 연동 패럴랙스는 사용하지 않는다.
- 영상·Lottie·reveal 모두 reduced-motion에서 정지 또는 즉시 전환되어야 한다.

## 9. Content rules

- 헤드라인: 사용자가 느끼게 될 변화. 기능명 나열 금지.
- 리드 문장: 1~2문장, 90자 안팎.
- CTA: 동사로 시작하고 목적이 분명해야 한다. 예: “티카 시작하기”, “우리의 장면 보기”.
- 카드 제목은 명사형보다 행동형을 선호한다.
- “감성적인”, “특별한” 같은 추상 수식어 대신 실제 장면을 쓴다.

## 10. Accessibility and QA

- 일반 텍스트 4.5:1, 큰 텍스트 3:1 이상 대비.
- 의미 있는 영상에는 자막/대체 설명을 제공하고 장식 영상은 `aria-hidden="true"`.
- 터치 타깃 44×44px 이상, 키보드 탐색 순서는 화면 순서와 일치.
- `100vh` 대신 `100svh`와 safe-area inset을 사용한다.
- 320, 390, 720, 840, 1280, 1440px에서 텍스트 충돌과 피사체 크롭을 검사한다.
- 3G/저전력/영상 실패 상태에서도 제목과 CTA가 즉시 보여야 한다.
- CLS 목표 0.1 이하: 이미지·영상에 aspect-ratio를 선할당한다.

## 11. 구현 구조

```text
public/
  assets/
    brand/
    hero/
    stories/
    video/
src/
  components/
    CapsuleNav
    CinematicHero
    HeroHeadline
    FloatingCTA
    EditorialMedia
    StoryCard
    QuoteBlock
  styles/
    tokens.css
    globals.css
```

컴포넌트는 색을 직접 쓰지 않고 semantic token만 사용한다. 이미지 경로는 컴포넌트 내부에 하드코딩하지 않고 콘텐츠 데이터로 주입한다.

## 12. 완료 기준

- 첫 화면에 제목, 설명, Primary CTA가 모두 보인다.
- 영상 없이도 동일한 메시지와 행동이 성립한다.
- 한 화면의 Primary CTA는 하나다.
- 모든 이미지가 정해진 비율과 반응형 소스를 가진다.
